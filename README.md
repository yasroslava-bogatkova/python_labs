##Задание 2

##Задание 3

##Задание 4

##Задание 5

##Задание 6

Запускается цикл на заданное число итераций, внутри которого строка разбивается по пробелам, берется последний элемент и если он равен строке True, то пополняется один счетчик, если нет- то второй.Программа выводит два этих счетчика




##Задание 7
